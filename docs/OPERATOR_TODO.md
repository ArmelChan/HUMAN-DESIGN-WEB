# 公開上線前須由營運者處理的事項

本文件列出程式無法代為決定、也不應由開發者推測的項目。條款、隱私聲明與版權指引都是**待法律審閱的草稿**，
沒有經過律師審核，也不保證在任何地區有效。欄位定義見 `src/data/legal/operator.ts`（值為 `null` 的欄位會在頁面上顯示「［待營運者填寫］」）。

## A. 阻擋公開發布

| 項目 | 現況 | 需要的決定或動作 |
| --- | --- | --- |
| 營運者名稱、聯絡方式、地址 | 未填 | 提供正式名稱與可用的聯絡管道 |
| 侵權通知聯絡方式 | 未填 | 建立電郵或表單；未建立前不得虛構 |
| 服務地區、準據法與管轄 | 未填，條款未寫入任何司法管轄區 | 依服務地區決定，並請法律專業人員審閱 |
| 法律審閱 | 未進行 | 條款、隱私聲明、版權指引三份文件逐一審閱 |
| 最低使用年齡與監護人安排 | 只有「依出生日期隱藏健康教育延伸內容」的產品限制 | 依服務地區法規確認；目前的限制不是年齡驗證 |
| 條款生效日期與變更通知方式 | 未填；本站沒有帳號或電郵名單 | 決定公告方式；版本號變更時網站會要求重新接受 |
| 網站託管方與其資料處理 | 未填 | 確認託管服務（例如 claude.ai Artifact 或 GitHub Pages）及其政策，補入隱私聲明 |
| 素材登錄中的「待確認」項目 | 9 項待確認（共 17 項，見 `src/data/legal/assets.ts` 與版權頁） | 逐項取得授權、改用自撰替代內容，或暫停發布該素材 |

待確認素材中，影響最大的是：閘門英文關鍵詞、通道英文名稱與中文暫譯、BodyGraph 圖形配置、「Human Design」名稱的商標狀態、閘門排列規則資料。

## B. 不阻擋，但需要決定

- 報告的商業轉售或商業再發布權限（目前不授予）。
- 收費模式：目前沒有任何收費、付款或訂閱功能；若日後收費，須補充消費者權利、退款與付款條款。
- 是否在來源頁加上 Vite 建置輔助程式碼的授權聲明（素材登錄 `vite-runtime`）。
- 是否加入 AI 功能：若加入，須先在隱私聲明中寫明接收者、傳送欄位、用途、已知保存安排，並提供不使用 AI 的選項（`src/lib/consent.ts` 已預留分開的 `aiTransfer` 欄位）。

## C. 已由程式處理、但仍有限制

- 條款接受紀錄只存在使用者瀏覽器（且只在使用者勾選保存時寫入本機），不構成跨裝置或對第三方的證明。
- 提問指引以關鍵字規則辨識危機訊號與敏感問題，會有漏判；它不提供任何地區的求助電話，因為網站不知道使用者所在地。
- 一般健康與心理教育只轉述 WHO 頁面要點並附查核日期；內容更新時需重新查核。
